LogEx's first public binary release: a standalone Ethereum event-log verification
client, local event store and SQL/query server with a browser dashboard.

## Download and start

Choose the matching archive below, verify it, extract it, and run `./logex sync`.
Open `http://127.0.0.1:8577/` for the dashboard. A Rust toolchain is not required.

| Platform | Asset |
| --- | --- |
| Linux x86_64, glibc 2.35+ | `logex-v0.1.0-x86_64-unknown-linux-gnu.tar.gz` |
| Linux ARM64, glibc 2.35+ | `logex-v0.1.0-aarch64-unknown-linux-gnu.tar.gz` |
| macOS 15+, Intel | `logex-v0.1.0-x86_64-apple-darwin.tar.gz` |
| macOS 15+, Apple Silicon | `logex-v0.1.0-aarch64-apple-darwin.tar.gz` |
| Windows | Use the matching Linux build inside WSL2 with Ubuntu 22.04+. |

[Installation and verification](https://github.com/tdenisenko/logex/blob/v0.1.0/INSTALL.md)
include checksums, GitHub build attestations, data-directory selection and WSL2
instructions. Each package includes licenses, dependency notices, a locked
dependency inventory and build metadata. The annotated tag and published assets
are immutable.

## Included

- Consensus-anchored receipt-log validation and contiguous verified coverage,
  including empty blocks, with canonical reorg handling.
- Local columnar storage, required event indexes and bounded online index/source
  verification without re-downloading Ethereum history.
- Read-only SQL, Ethereum-style log filtering, gRPC and live WebSocket queries,
  plus the built-in dashboard.
- LogEx SQL conveniences including `event'…'`, `address'…'`, `LATEST` and exact
  integer sums of supported log payloads. See the
  [SQL reference](https://github.com/tdenisenko/logex/blob/v0.1.0/SQL.md).
- Bounded shared query admission/memory, coverage checks, storage health
  monitoring and optional external-volume identity protection on Linux/macOS.

## Compatibility and operating notes

- Fresh mainnet synchronization needs a recent trusted weak-subjectivity
  checkpoint. The default command uses a two-of-three checkpoint-service quorum;
  understand the [trust model](https://github.com/tdenisenko/logex/blob/v0.1.0/README.md#what-logex-verifies).
- Historical synchronization and indexing need substantial SSD space and time.
  Queries reject requested ranges that are not yet verified.
- macOS binaries have an ad-hoc integrity signature and GitHub build provenance;
  they are **not Apple Developer ID signed or notarized**. Per-app approval may
  be required; the installation guide explains it.
- Native Windows is not supported in this release. WSL2 uses the Linux build;
  no separate WSL2 mainnet acceptance run is claimed.
- This is version `0.1.0`, not a promise of stable storage formats or APIs.
  Stop the node and preserve backups before future upgrades.
- Results describe event logs, not arbitrary EVM state, current balances or
  generic native-ETH transfers. Query performance depends on the workload;
  this release does not promise a latency target.
- Prior mainnet acceptance has finite source/range scope. It does not establish
  an independent re-fetch and verification of every historical Ethereum receipt.
