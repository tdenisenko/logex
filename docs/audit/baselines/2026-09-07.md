live segments were compacted. Maximum RSS is for the entire benchmark process

## Validation and findings

- Original workspace baseline: 716 passed, zero failed, one ignored benchmark.
- Final workspace suite: 720 passed, zero failed, one ignored benchmark.
- Formatting, locked all-target checking, strict all-target Clippy, explicit
  workspace doc tests and release node build passed locally. There are currently
  no runnable doc-test examples; the explicit gate completed successfully.
- Both 200,000-row profiles passed five runs with exact native rows, SQL counts
  and order, concurrent query results, historical ingest and reopen assertions.
- The original page-order regression failed with `requested row is before the
  current page range`; its focused unit test passes after the fix.
- Existing dependency future-incompatibility warnings remain. A focused
  debug-only query test link emitted the macOS large-unwind-section warning;
  the tests completed successfully and the release binary linked successfully.
- RustSec reported ten original-lockfile vulnerability matches, documented in
  [dependency review](../dependencies.md). This baseline does not resolve them.
- macOS/Linux GitHub CI and merge status belong in the PR; local results do
  not substitute for those gates. No deployment, full-chain benchmark, or
  24-hour staging soak has been performed.
